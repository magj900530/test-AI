# 🏨 酒店价格对照小程序

跨平台酒店比价工具 — 基于当前位置或自选地点，查看周边酒店的跨平台价格对比，综合排序后获得推荐方案。

## 技术栈

- **框架**: uni-app (Vue 3 + Vite)
- **状态管理**: Pinia
- **地图**: 高德地图 Web API
- **目标平台**: 微信小程序（可一键发布到 H5/支付宝/抖音小程序）

## 快速开始

```bash
# 安装依赖
npm install

# 启动微信小程序开发
npm run dev:mp-weixin

# 启动 H5 开发
npm run dev:h5
```

## 项目结构

```
hotel-compare/
├── pages/
│   ├── index/          # 首页 — 地图 + 酒店列表
│   ├── detail/         # 酒店详情 — 照片/价格对比/跳转
│   ├── recommend/      # 优选推荐页
│   └── search/         # 搜索 & 地点选择
├── components/         # 可复用组件
├── stores/             # Pinia 状态管理
├── data/               # 模拟数据
├── utils/              # 工具函数
└── static/             # 静态资源
```

## 核心功能

| 功能 | 说明 |
|------|------|
| 📍 智能定位 | GPS 自动定位 + 地图手动选点 + POI 搜索 |
| 🔍 范围筛选 | 1km / 3km / 5km / 10km 预设半径 |
| 💰 价格对比 | 美团/携程/去哪儿/飞猪 四平台并排展示 |
| 📊 综合排序 | 加权算法（价格35%+评分25%+距离20%+评价12%+星级8%） |
| 🏆 优选推荐 | 分层 Top 3 + 自动生成推荐理由 |
| ⭐ 收藏对比 | 最多 4 家酒店横向对比 |

## 配置

1. **高德地图 Key**: 替换 `utils/amap.js` 中的 `AMAP_KEY`
2. **微信小程序 AppID**: 替换 `manifest.json` -> `mp-weixin.appid`
3. **图标**: 替换 `static/icons/` 下的占位图标为实际设计图标
4. **酒店图片**: 替换 `static/images/` 下的占位图片

## 数据说明

MVP 阶段使用内置模拟数据（`data/hotels.json`），覆盖：
- 深圳（福田/南山）— 25 家酒店
- 北京（国贸/CBD）— 25 家酒店
- 上海（陆家嘴/南京路）— 25 家酒店

后续可通过 `utils/request.js` 中预留的接口对接真实 API。
