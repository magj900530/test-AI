# 微信 iLink ClawBot 远程控制 — 操作手册 V4.0

## 系统架构

```
微信 App ── iLink API ──→ cc-weixin 后台进程 ──→ Claude Agent SDK ──→ DeepSeek
                              │                        │
                              │  审批中继（文件协议）     │  独立会话
                              │                        │
VS Code Claude ──→ PreToolUse Hook ──→ pending_approval.json ──→ 微信审批
                ──→ PreCompact Hook ──→ 同上
                ──→ SessionStart Hook（模式注入）
                ──→ PostToolUse Hook（进度记录）
```

两条通道各司其职：

| 通道 | 载体 | 适用场景 |
|------|------|----------|
| VS Code Claude | IDE 内交互 | 日常编码、复杂重构、本地调试 |
| 微信 ClawBot | 手机微信 | 离开电脑后查看状态、审批高危操作、轻量问答 |

## 一、每日开机

1. 登录 Windows → cc-weixin **自动启动**（静默，无窗口）
2. 验证：微信发给「微信 ClawBot」任意消息，有回复即正常
3. 若无回复：

   ```
   # 方案A：双击静默启动
   C:\Users\47150\.cc-weixin\start-silent.vbs

   # 方案B：终端手动启动（可看日志）
   cc-weixin --no-tui

   # 方案C：重新扫码登录（Token 过期时）
   cc-weixin --no-tui --login
   ```

> 关机前不需要手动关，直接关机即可。下次开机自动恢复。

## 二、本地模式 vs 远程模式

| | 本地模式（默认） | 远程模式 |
|---|:---:|:---:|
| VS Code 操作 | 正常 | 正常 |
| 微信推送进度 | ❌ 不推送 | ✅ 推送 |
| 微信推送审批 | ❌ 不推送 | ✅ 推送 |
| 微信问答 | ✅ 正常 | ✅ 正常 |

### 切换方式

在微信发送：

| 指令 | 效果 |
|------|------|
| `开启远程` | 切换到远程模式，高危操作会推微信审批 |
| `关闭远程` | 切回本地模式，不再推送任何通知 |

> 模式切换后，**下次 VS Code 新会话**生效，当前会话不受影响。

## 四、远程审批高危操作（核心功能）

### 4.1 触发条件

当你在 VS Code 中让 Claude 执行以下操作时，**远程模式下**会先推微信确认：

| 风险等级 | 操作类型 | 示例 |
|----------|----------|------|
| 高危 | 强制删除 | `rm -rf`、`rmdir /s` |
| 高危 | 强制推送 | `git push --force` |
| 高危 | 权限变更 | `chmod 777` |
| 高危 | 数据库破坏 | `DROP TABLE`、`TRUNCATE`、`DELETE FROM` |
| 高危 | 磁盘操作 | `format`、`dd if=` |
| 中危 | 敏感文件写入 | `.env`、`settings.json`、凭据文件 |

### 4.2 审批流程

```
VS Code 执行高危操作
       ↓
微信收到审批消息：
  ⚠️ 高危操作审批 [1712345678]
  ━━━━━━━━━━━━━━━━
  风险：强制递归删除
  工具：Bash
  命令：rm -rf /tmp/build/*
  ━━━━━━━━━━━━━━━━
  回复「同意」或「拒绝」（15分钟自动拒绝）
       ↓
你回复「同意」→ VS Code 继续执行
你回复「拒绝」→ 操作被拦截
你回复其他问题 → 自动拒绝当前操作 + 转发问题给 Claude 回答
       ↓
15 分钟无回复 → 自动拒绝
```

### 4.3 审批时提问

如果对操作有疑问，直接回复你的问题（不用发「同意」或「拒绝」）：

```
你：这个文件删了会影响什么？
系统：⏸️ 审批已取消，正在处理你的问题…
Claude：删除 /tmp/build 只影响编译缓存，不影响源码…
```

这样既不会误操作，又能先搞清楚情况。

## 五、上下文压缩（Compact）

### 5.1 自动触发

当 VS Code 会话上下文占用达到 **40%**，系统会自动发起 compact 审批：

```
📦 上下文压缩建议
━━━━━━━━━━━━━━━━
上下文压缩（当前占比约 42%，建议清理）
━━━━━━━━━━━━━━━━
回复「同意」执行 compact（完成后自动续跑）
回复「拒绝」或任何问题（5分钟超时自动同意）
```

- 同意 → compact 执行 → 自动恢复任务
- 拒绝 → 跳过本次 compact
- 超时 → 自动同意（compact 非破坏操作，安全）

### 5.2 手动发起

微信发送 `compact`，系统会回复指引信息。

## 六、安全模式与提权（微信问答通道）

微信问答通道默认**安全模式**，不能写文件：

| 级别 | 写文件 | 执行命令 | 触发 |
|------|:---:|:---:|------|
| 安全（默认） | ❌ | ✅ 安全命令 | 无需操作 |
| 临时提权 | ✅ 一次 | ✅ | `提权` |
| 永久解锁 | ✅ | ✅ | `永久提权` |
| 恢复安全 | ❌ | ✅ | `锁定` |

> 注意：这是微信通道（SDK 会话）的权限控制，不影响 VS Code 通道。

## 八、自动保存（Git Auto Save）

每次 VS Code 会话结束时，Stop hook 自动执行：

```
会话结束
    ↓
检测活跃项目目录
    ↓
git status --porcelain  →  无改动 → 跳过
    ↓ 有改动
git add -A
    ↓
git commit -m "auto: session snapshot 2026-08-03 14:30"
    ↓
git push
```

**提交信息格式**：`auto: session snapshot YYYY-MM-DD HH:MM`

**常见场景**：
- 人在外面、VS Code 会话超时断开 → 代码自动保存到 GitHub
- 离开电脑前忘了 commit → Stop hook 兜底
- 后台项目会话冻结前 → 最后状态自动推送

> 注意：只对当前活跃项目生效。如果 `git push` 失败（如网络问题），改动已 commit 但未 push，下次手动推送即可。

## 十、离开 / 回到电脑

### 出门前

1. 微信发 `开启远程` 激活远程模式
2. VS Code 保持打开（Claude 会话继续）
3. 出门后微信保持联网

### 出门后想远程干活

1. 微信发消息给 ClawBot → 新开独立会话
2. 需要描述当前任务（微信会话接不上 VS Code 的对话历史）：
   ```
   继续 hotel-compare 项目，帮我把搜索结果页的分页改成无限滚动
   ```
3. 如果 VS Code 那边 Claude 在执行任务并触发高危操作 → 微信会收到审批通知

### 回到电脑

1. 正常继续 VS Code 工作
2. 如果需要安静 → 微信发 `关闭远程`

## 十一、停用 cc-weixin

```
# 终端执行，杀掉后台进程
taskkill /f /im node.exe
```

> 这会把所有 Node.js 进程都杀掉。如果有其他 Node 项目在跑，用任务管理器精确关闭 cc-weixin 的进程。

恢复：双击 `start-silent.vbs` 或在终端跑 `cc-weixin --no-tui`。

## 十二、故障排查

| 现象 | 检查 |
|------|------|
| 微信发消息无回复 | ① 电脑开机了吗？② 任务管理器有 `node.exe` 吗？③ 终端跑 `cc-weixin --no-tui` 看报错 |
| 回复「无法连接」| DeepSeek API 密钥过期？`C:\Users\47150\.env` 检查 `ANTHROPIC_AUTH_TOKEN` |
| Token 过期 | 终端执行 `cc-weixin --no-tui --login`，手机扫码重新授权 |
| VS Code 操作没推微信审批 | ① 远程模式开了吗？② cc-weixin 在运行吗？③ VS Code 窗口 Reload 过吗？ |
| PreCompact 报错 | VS Code 需 Reload Window 以加载最新的 settings.json 配置 |
| 审批消息收不到 | 检查 `~/.claude/state/pending_approval.json` 是否存在，查看 cc-weixin 终端日志 |
| 写入被拦截（微信问答）| 发送「提权」临时放行，或「永久提权」长期解锁 |
